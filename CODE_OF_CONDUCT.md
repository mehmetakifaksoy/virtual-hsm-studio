# Code of Conduct

Virtual HSM Studio aims to maintain a professional, collaborative,
and technically focused open-source environment.

## Expected Behavior

Contributors should:

- Communicate respectfully.
- Give constructive technical feedback.
- Keep discussions focused on the project.
- Respect different experience levels and viewpoints.
- Handle security-sensitive information responsibly.

## Unacceptable Behavior

The following are not acceptable:

- Harassment or personal attacks.
- Publishing private or sensitive information.
- Intentionally disruptive behavior.
- Sharing secrets, credentials, PINs, private keys, or production HSM data.

## Security Issues

Security vulnerabilities should not be disclosed through public issues.

Please follow the process described in SECURITY.md.
